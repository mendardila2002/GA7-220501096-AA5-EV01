Documentación de Endpoints (Especificación Técnica)

Contratos de entrada, salida y códigos de estado HTTP implementados

POST /api/auth/login

Valida credenciales de acceso. Cumple el requerimiento principal de la evidencia:

  • 200 OK: { "exito": true, "mensaje": "Autenticación satisfactoria" }
  • 401 Unauthorized: { "exito": false, "mensaje": "Error en la autenticación: Credenciales inválidas..." }
  • 400 Bad Request: Campos faltantes o vacíos.
POST /api/auth/register

Registra un nuevo usuario con contraseña cifrada (bcrypt):

  • 201 Created: { "exito": true, "mensaje": "Registro satisfactorio..." }
  • 409 Conflict: Usuario ya existente.
  • 400 Bad Request: Validación de longitud y obligatoriedad.
GET /api/auth/users

Retorna la lista de usuarios registrados sin exponer datos confidenciales.

  • 200 OK: Array con usuarios, id, nombre y roles.
